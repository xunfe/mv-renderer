# 构建说明

本文假设仓库根目录为 `mv-renderer/`。

## 0. 总览

```
web/ ──┬── tools/prepare_assets.py ──> android/app/src/main/assets/{www,engine,execute}
       └── cp -r ─────────────────────> pc/web
```

安卓和 PC 共用 `web/`；`dshpv/`、`space/` 是 PC 独有页面，安卓端会隐藏对应入口。

---

## 1. 安卓（Android 24+）

### 1.1 环境

- JDK 17
- Android SDK Platform 35 + Build-Tools 35.0.0
- Gradle 8.7+（仓库没有放 wrapper 二进制）

### 1.2 准备资源

```bash
python3 tools/prepare_assets.py
```

脚本会清空并重建 `android/app/src/main/assets/`：

| 仓库目录 | assets 目录 | 页面路径 |
|---|---|---|
| `web/`（除 `engine/ execute/ dshpv/ space/`） | `assets/www/` | `/…` |
| `web/engine/` | `assets/engine/` | `/engine/…` |
| `web/execute/` | `assets/execute/` | `/execute/…` |

`web/execute/song.flac` 默认不在仓库里（个人购买的音频），没有它离线版 world.execute (me) 没有声音，其余功能不受影响。

### 1.3 签名配置

`android/keystore.properties`（已加入 `.gitignore`）：

```properties
storeFile=/绝对路径/ks.jks
storePassword=******
keyAlias=k
keyPassword=******
```

放一把长期使用的证书，**以后每次升级都必须用同一把**，否则覆盖安装会报签名冲突、只能卸载重装。

### 1.4 构建

```bash
cd android
gradle assembleRelease        # 或 ./gradlew assembleRelease
```

产物：`android/app/build/outputs/apk/release/app-release.apk`

`versionCode` 为 10000（`1*10000 + 0*100 + 0`），大于历史上所有 10.x 构建（最高 27），可以直接覆盖安装。

### 1.5 快速重打包（可选）

如果机器上没有 Android SDK，或只想在已有的基线 APK 上改版本号：

```bash
python3 tools/repack_apk.py \
  --base 旧版.apk --name 1.0.0 --code 10000 \
  --ks ks.jks --ks-pass ****** --ks-alias k \
  --out 新版.apk
```

原理：解析二进制 `AndroidManifest.xml`（AXML），原位改 `versionCode` 与 `versionName`（字符串池里等长替换），再用 `zipalign -p 4` + `apksigner`（v2/v3）重签。媒体条目保持 STORED，Range 不受影响。

## 2. Windows（Electron）

```bash
cp -r web pc/web
cd pc
npm install          # 只有 adm-zip
npx electron .
```

- `pc/main.js` 里 `WEB_ROOT = __dirname/web`，`pc/server.js` 起一个只监听 `127.0.0.1` 的静态服务器（与安卓 `AssetServer` 行为对齐：`/execute/`、`/engine/`、`/custom/<id>/` 是特例）。
- `pc/dshpv/` 是 DSH PV 渲染工程，需要 `pc/runtime/`（内置 Python + ffmpeg，体积太大不在仓库里）。缺失时页面可以打开，但点「开始渲染」会提示运行环境缺失。
- 免安装版：准备一份 Electron 运行时，令 `resources/app` 指向 `pc/`，整目录压缩。

---

## 3. 离线渲染（可选）

`tools/offline-render/` 是通过 `@napi-rs/canvas` 在 Node 里直接跑 MV 绘制代码、逐帧出图的小工具：

```bash
npm i @napi-rs/canvas
node tools/offline-render/batch.js 0 300 /tmp/frames 60   # 起帧 止帧 输出目录 fps
```

脚本默认把 `../` 当 MV 目录、从系统路径注册 Noto CJK 字体；换到其他 MV 时改一下 `MV` 和字体路径即可。网页版（`web/mv/*/`）本身就是最终渲染器，离线工具只用于出静帧/母带。
