# MV 合集 · DSH 插件 使用说明

**v__VERSION__** · 把「代码 MV」做成 DSH 里的一个合集页面：内置 P(doom)，四个合集包按需下载；自己可以新建合集、
导入 zip，DSH 也能直接把做好的 MV 发布进来。

---

## 目录里有什么

解压后打开文件夹，第一层就是：

```
dsh-mv-hub-__VERSION__/
├── 安装.sh                  ← 一键安装脚本
├── 使用说明.md              ← 本文件
└── package/
    └── dsh-mv-hub-__VERSION__.tgz   ← 插件本体（安装脚本会用它）
```

---

## 安装

### 方式一：一键脚本（推荐）

1. 把 zip 解压，打开解压出来的文件夹。
2. 在 DSH 的终端里（或 DSH 所在的 Linux / Android 容器里）进入这个目录。
3. 运行：

   ```bash
   bash 安装.sh
   ```

   默认装进 `web` profile。如果 DSH 用的是别的 profile：

   ```bash
   bash 安装.sh 你的profile名
   ```

4. **完全退出并重新打开 DSH**。Host 插件和页面要重启后才加载。
5. 左侧栏出现「MV 合集」，点开就能用。

脚本做的事就一件：`dsh plugin add` 安装包并把它挂进 profile 的 bundle 列表（插件为启用状态），
不会碰你的其它设置。

### 方式二：插件管理器

DSH 设置 → 插件 → 安装，target 填 `package/dsh-mv-hub-__VERSION__.tgz` 的**绝对路径**，装完重启。

### 方式三：命令行

```bash
dsh plugin --profile web add /绝对路径/dsh-mv-hub-__VERSION__.tgz
```

> Windows：DSH 桌面版如果没有把 `dsh` 放进 PATH，请用方式二，或到 DSH 安装目录里找 `dsh.cmd`。

## 装完怎么用

### 页面

左侧「MV 合集」：

- **默认 MV**：打开就能播 P(doom)。
- **合集扩展**：AI娘 / 科普简史 / 大肥鱼的情书 / word excuse me 只显示封面；第一次播放时自动从 Cloudflare R2
  下载（4 MB～229 MB），下载过的留在本机，之后离线可看。
- **我的合集**：右上角「新建合集」；合集只是归档，不会复制 MV 文件。
- **导入 MV**：右上角「导入 MV」，选构建好的 zip（里面要有 `index.html`），可顺便归入某个合集。
- **收作品**：打开合集 →「添加作品」，内置作品、合集包作品、导入/发布的 MV 都能勾进来。
- **删除 / 移出**：作品卡片右上角 ×；删除导入的 MV 会真的删掉本机文件。
- **刷新**：右上角圆形箭头。DSH 刚发布完新 MV 时，点一下刷新就能看到。

### 让 DSH 帮你做 / 发布

直接在对话里说，比如：

> 给我做一支 30 秒的氛围 MV，蓝色调，发布到「我的作品」合集里。

DSH 会读内置 MV 的源码和画面帧当参考，在工作区构建，然后调用 `mv_hub_publish` 直接发布进插件。
发布完你**刷新页面**就能看到、能播。它不会自动轮询，刷新这一步要你自己点。

DSH 也可以：读某支 MV 的源码、拿参考画面帧、把已有 zip 导入、新建/改名/删除合集、往合集里加作品。

### 模型说明是「按需加载」的

插件里内置了一份给模型看的说明（`docs/MODEL.md`），安装后注册成名为 `mv-hub` 的技能：

- 平时只出现在技能目录里一行（名称 + 一句话），**不占上下文**；
- 当你要做 MV / 管理合集 / 发布时，模型才会按需读取完整说明；
- 所以「装了插件但不用 MV」不会浪费模型资源。

## 给外部 agent / 别的 DSH 用

插件同时开了 HTTP 接口（DSH 本机，默认 `http://127.0.0.1:3080`）：

| 动作 | 接口 |
|---|---|
| 发布 MV | `POST /mv-hub/api/publish`（JSON，files 支持 text/base64） |
| 导入 zip | `POST /mv-hub/api/import?name=x.zip`（body 是 zip） |
| 合集管理 | `POST /mv-hub/api/collection/save|delete|items` |
| 读目录 / 源码 / 帧 | `GET /mv-hub/api/catalog`、`/source`、`/frames` |
| 接口自描述 | `GET /mv-hub/api/help` |

完整字段见插件包里的 `docs/API.md`，或直接读 `/mv-hub/api/help`。外部请求只能传内容，不能指定服务器本地路径。

## 数据存在哪

```
$DSH_HOME/mv-hub/
├── pkgs/                    从 R2 下载的合集包
├── user/collections.json    你的合集
└── user/mvs/<id>/           导入 / 发布的 MV（含 meta.json、frames/）
```

`$DSH_HOME` 默认是 `~/.dsh`。备份就说这个目录；删 `user/` 会清空自己的合集和导入的 MV（内置作品不受影响）。

## 卸载

- 插件管理器里移除 `dsh-mv-hub`；或
- 命令行：`dsh plugin --profile web remove dsh-mv-hub`；然后重启。
- 数据目录 `$DSH_HOME/mv-hub/` 会保留，确定不要了再手动删。

## 常见问题

**装完没看到「MV 合集」？**
没重启，或装到了别的 profile。确认启动 DSH 用的是你安装的那个 profile。

**页面能开，但新建合集 / 导入按钮报错？**
插件 Host 部分还是旧进程。完全退出 DSH 再打开，不要只是关页面。

**导入 zip 失败？**
zip 里必须有 `index.html`（允许套一层项目目录）。入口是 `src/index.html` 这种深层结构不行，先把构建产物
放到压缩包根目录。也检查文件是不是太大（浏览器上传上限 3 GB）。

**导入后画面白屏 / 404？**
MV 里的资源要写**相对路径**（`./assets/x.png`）。写成 `/assets/x.png` 这种根路径会 404。共享播放脚本
`/mv-return.js` 等插件会自动处理。

**下集合包很慢？**
包从 Cloudflare R2（亚太）拉，最大 229 MB。下过的会留在本机，之后不用再下。

**能把 3080 开放到公网给别的机器发布吗？**
不建议。接口无鉴权；需要跨机器时让那台机器和本机在同一可信网络，或手动把 zip 传过来导入。
