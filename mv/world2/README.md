# 世界还在写 · 墨海版（模仿版）

同一首歌，另一套「墨 / 海 / 页」的视觉；画面由小黑重写，人物直接沿用原版角色贴图，未改画。
播放结束会自动回到「AI娘角色主题曲MV」合集。

## 运行依赖

本目录的代码以 AGPL-3.0 开源，但**不包含**原版角色、字体、音轨与逐字时间轴。
运行时从 `../world/` 读取：

```
../world/src/lib.js          共用绘制工具
../world/assets/chars/*.png  原版角色贴图（小伙伴ko）
../world/fonts/*.ttf         Noto Serif/Sans SC（OFL）
../world/analysis/*.json     节拍与歌词时间轴
../world/song/世界还在写.mp3  原版音轨
```

这些资源由原作者 **B站 小伙伴ko（UID 105330745）** 授权内置，**不在本仓库中**。
安装带内置原版的 APK / PC 包即可直接播放；单独 clone 代码时请自行补齐上述素材。
