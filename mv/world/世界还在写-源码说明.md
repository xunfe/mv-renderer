# 《世界还在写》MV 渲染源码

这是精简后的源码交流包，不是成片、通用动画编辑器或移动端 SDK。画面由浏览器 Canvas 2D、WebGL 2 和透明角色贴图合成；角色不是纯代码绘制。分镜和动画保留原实现，没有改写成另一套引擎。

## 直接预览

需要 Node.js 20 或更新版本，以及支持 WebGL 2、OffscreenCanvas 的桌面 Chrome。预览不需要安装 npm 依赖，不使用 API，也不需要密钥。

在解压目录运行：

```sh
node tools/serve.js
```

打开 [完整版预览](http://127.0.0.1:8123/index.html?cut=full&hook=1)。点击画面播放或暂停，左右方向键跳转 5 秒。停止服务用 Ctrl+C。不要直接双击 HTML 文件。

- `?cut=full&hook=1`：现行完整版剪辑，跳过原曲前 14.35 秒，约 203.81 秒。
- `?cut=full`：保留原曲前奏，约 218.16 秒。
- `?hook=1`：短版剪辑，约 88.35 秒。
- 追加 `&t=60`：从输出时间轴第 60 秒开始。

服务器仅监听本机，不需要提供账号、Cookie 或私有服务。

## 接入自己的播放器

保留目录结构，通过 HTTP 提供 `index.html`。等待 `await window.__ready` 后，调用 `window.seek(t, 1)` 绘制指定秒数的画面；`window.DUR` 是当前剪辑时长。独立播放器可使用 `?cut=full&hook=1&render=1`，该模式不启动自带音频播放器。

`t` 是剪辑后的输出时间。采用 `hook=1` 时，外部完整音乐应从原曲 14.35 秒开始，与画面同步。短版使用 `song/cut_v2.wav`，同样跳过 14.35 秒。

角色姿势、眼部遮罩及清单中的定位参数都有依赖，不能只复制 JS 后把图片删掉。字体影响中文排版和文字测量，也应一起保留。

## 可选：离线导出

导出工具另外需要安装桌面 Chrome 和 Playwright Core；合成视频需要自行安装 FFmpeg。依赖和浏览器本体没有装进本包。

```sh
npm install
node tools/render.js --full --hook --keys 0,30,90,150,200
```

上面只输出 5 张关键帧到 `frames/keys/`。确认能运行后，再按需渲染整片：

```sh
node tools/render.js --full --hook --fps 60 --q 4 --out frames/full
```

渲染按帧截图，耗时和临时空间可能很大；请先导出短片段。`--from 0 --to 300` 表示只导出第 0 帧至第 299 帧，`--force` 才会覆盖已有序列帧。

在项目根目录合成完整版本，目标 `mv.mp4` 已存在时本命令会拒绝覆盖：

```sh
ffmpeg -n -framerate 60 -i frames/full/f_%06d.png -ss 14.35 -i "song/世界还在写.mp3" -af "afade=t=in:st=0:d=0.02" -vf "scale=out_color_matrix=bt709:out_range=tv,format=yuv420p" -c:v libx264 -preset slow -crf 15 -colorspace bt709 -color_primaries bt709 -color_trc bt709 -c:a aac -b:a 320k -shortest -movflags +faststart mv.mp4
```

默认输出为 1920 × 1080。`--ss 2` 可提高画布分辨率，但分享包只保留标准角色贴图，没有原工程的 2 倍放大贴图，因此不等于原版 4K 角色细节。

## 文件范围与改动

- `src/`：分镜、剪辑表、字幕、特效及角色形变代码；入口为 `main.js`。
- `assets/chars/`：清单实际加载的透明角色图和眼部遮罩。已移除清单中的本机来源路径。
- `analysis/`：仅 4 份节拍和字幕时序 JSON，不包含调研、人声分离结果或分析日志。
- `fonts/`：运行所需的两款字体及许可说明。
- `song/`：完整音乐和当前短版剪辑，清除了可移除的容器元数据，音频未重新编码。
- `tools/`：本机静态服务器和按帧导出工具。渲染依赖改为常规 npm 包，去掉作者电脑的绝对路径，并补充异常退出时的资源关闭。

未附带成片、封面、生成原图、提示词、调研记录、历史版本、平台发布资料、账号配置、日志、模型、依赖安装目录或高清放大副本。没有调用任何图片、视频或语音生成服务。
