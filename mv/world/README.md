# 《世界还在写》原版（仅内置，不随开源仓库分发）

这个目录是 **原版 MV** 的运行资源与分镜代码：

- `src/`：原版引擎与分镜
- `assets/chars/`：小伙伴ko 的角色贴图与眼部遮罩
- `fonts/`：排版所需字体（OFL）
- `song/world.mp3`：原版音轨（**文件名必须是 ASCII**：安卓的 AssetServer 以前不还原 URL 里的中文，
  叫「世界还在写.mp3」会 404；现在服务端已修，但文件名保持 ASCII 双保险）
- `song/cut_v2.wav`：103 秒预告版音轨（`?cut=short` 时用；不放也行，只是预告版没声音）
- `analysis/`：节拍与逐字歌词时间轴

页面 `index.html` 是我们自己写的（在仓库里），负责封面、五档画质、播完返回合集和缺素材自检；
`src/` 以下全部是原作者的代码，只在安装包里内置。

源码与角色素材由原作者 **B站 小伙伴ko（UID 105330745）** 提供，**已取得授权在本应用中内置**；
但不随本开源仓库分发，也不在 AGPL-3.0 的授权范围内。请勿从本仓库再分发这些文件。

模仿版 `web/mv/world2/` 的代码是开源的；想在本机跑模仿版，需要把上面这些原版资源放回本目录
（或安装带内置原版的 APK / PC 包）。
