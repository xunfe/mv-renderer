第三方离线渲染工程 · 作者 MisakaZentai
这支 PV 不是网页播放器，而是一套 Python + Electron + ffmpeg 的离线渲染工程： 左边是 DSH 聊天窗口逐帧截图，右边是 TUI 可视化，全部由代码生成。 需要先在本机渲染成视频才能观看，首次约 10–30 分钟（取决于 CPU），渲染在后台进行，期间界面可能会略卡，属于正常现象。
工程母版是 1280×720 / 24fps 的像素画，4K、2K 都是它的整数倍最近邻放大，帧率统一 24fps。
代码 MIT，画面 CC BY-NC-SA 4.0；歌曲使用应用内已内置的 world.execute (me) 音频。
仓库：github.com/MisakaZentai/world-execute-me-dsh-pv
画质档位帧率统一 24fps（工程原生）
高级：指定 GPU 合成用的 Python（可选）
应用内置的便携 Python 不带 torch，所以默认只能用 CPU 合成。 机器上装过带 CUDA 的 PyTorch（比如 ComfyUI 自带的 python_embeded）时，把路径填进来就能开 GPU 合成。
